# ONG Solidária

Projeto desenvolvido para o Projeto Integrador Extensionista II.

## Sobre o projeto

O site da ONG Solidária tem como objetivo divulgar o propósito da organização e incentivar ações de solidariedade. A página também consulta uma API para verificar seu funcionamento e exibe a data e a hora atuais.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vite+
- Node.js
- Express
- dotenv

## Requisitos

- Node.js instalado
- pnpm instalado

## Como executar o projeto

1. Clone ou baixe este repositório.
2. Instale as dependências:

   `pnpm install`

3. Crie um arquivo `.env` na raiz do projeto com o conteúdo:

   `PORT=3000`

4. Abra um terminal e inicie a API:

   `pnpm run api`

5. Em outro terminal, inicie o site:

   `pnpm run dev`

6. Acesse `http://localhost:5173` no navegador.

## Teste da API

Acesse `http://localhost:3000/api/health` para verificar a resposta da API.
